# Changelog

Notable user-facing changes are recorded here. Dates for published versions are
based on their first PyPI upload.

## 2.0.7 - Unreleased

### Changed

- Restored active stability maintenance and removed the obsolete deprecation notice.
- Moved project metadata to a modern `pyproject.toml` build.
- Updated ownership and project links to DOYDL Technologies.
- Deferred CPI downloads and GUI construction until those features are used.
- Added explicit request timeouts and clearer CPI data errors.
- Restored GUI images and icons omitted from the source repository.
- Added automated tests and cross-platform continuous integration.

## 2.0.6 - 2024-09-06

### Changed

- Marked the project inactive and directed users to its former successor.

## 2.0.5 - 2024-09-05

### Fixed

- Corrected GUI icon packaging and icon-path handling.

## 2.0.4 - 2024-09-05

### Fixed

- Published packaging corrections following the GUI release.

## 2.0.2 - 2024-07-22

### Added

- Added a graphical interface for adjusted values, historical comparisons, and
  current-year monthly changes.
- Added historical comparison and current-year methods to the calculator.

### Fixed

- Improved annual-average fallback and incomplete-data handling.

## 1.0.0 - 2024-07-22

### Added

- Released the original CPI-based inflation adjustment API.
